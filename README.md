# ShipTrack Pro

A shipment tracking and logistics management application built with Spring Boot and React.

> 🚧 This project is currently under development.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- PostgreSQL
- Maven

### Frontend
- React
- React Router
- Axios

### Tools
- Git
- Docker
- Postman

## Current Progress

- Frontend structure

## Planned Features

- Shipment Management
- Shipment Tracking
- Notifications
- Analytics Dashboard

## Getting Started

### Clone the repository

```bash
git clone https://github.com/loharaniket/ShipTrack-Pro.git
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
